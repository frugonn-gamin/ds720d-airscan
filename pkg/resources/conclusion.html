Installation terminée

  1. Branchez le DS-720D en USB (s'il l'était déjà, débranchez-le puis rebranchez-le).
  2. Si macOS demande d'autoriser ds720d-agent à accéder aux volumes amovibles, cliquez sur « Autoriser ».
  3. Ouvrez Transfert d'images : « Brother DS-720D » apparaît dans la colonne de gauche.
  4. Glissez une feuille dans le scanneur, choisissez couleur / recto-verso / résolution, puis « Numériser ».

Le scanneur est aussi disponible dans Aperçu (Fichier › Importer depuis le scanneur).

Journaux : ~/Library/Logs/ds720d-usbd.log et /var/log/ds720d-airscan.log
